# Identidade visual

- `logo-original.png`: referência de 100 × 40 px preservada do repositório anterior.
- `logo-gitap-transparente.png`: restauração em 1855 × 545 px, PNG RGBA com transparência real.
- `logo-gitap-clara.png`: versão clara do mesmo desenho para o rodapé escuro.

A restauração utilizou a ferramenta integrada de geração/edição de imagens, seguida de remoção local do fundo expressamente autorizada pelo cliente. A logo deve ser validada pelo titular da marca; a versão vetorial oficial é preferível quando disponível.

Prompt de restauração: “Restaurar a logo original GITAP ADM em alta resolução, preservando as letras geométricas finas, o broto de cinco folhas sobre arco central, a disposição horizontal, o verde da marca e o slogan exato ‘Gerando Negócios Sustentáveis’. Gerar PNG com fundo transparente, sem sombras, efeitos ou elementos adicionais.”

Fontes: https://github.com/matheuscurym/gitapadm-website/blob/main/logo1.png e https://www.facebook.com/Gitap.adm/.
